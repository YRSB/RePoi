# 分流标签规范 (Triage Labels)

本项目 Issue 跟踪统一使用以下五个标准分流标签：

| 标签 | 含义与流转规则 |
|---|---|
| `needs-triage` | 新建待评审：等待维护者评估需求合理性与排期 |
| `needs-info` | 信息补全：缺少复现日志、截图或具体规格，等待提报人回复 |
| `ready-for-agent` | 规格完备：已明确实现路径与验收条件，可由智能体自主执行 |
| `ready-for-human` | 人工介入：涉及高敏感权限、设计主观决策或物理真机测试 |
| `wontfix` | 拒绝/不处理：非应用范畴、重复提报或不符架构预期 |
