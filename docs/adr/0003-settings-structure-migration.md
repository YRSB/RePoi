# ADR-0003: 设置页结构与迁移清单

## 状态
已采纳 (Accepted) - 2026-11-04

## 上下文与问题陈述
RePoi 设置页需同时承载 Hpoi 原版设置迁移与 RePoi 自身能力（主题、缓存）。原版设置页经逆向产物确认：设置主页 3 组 13 入口 + 独立首页设置。需决定迁移清单、分组结构、导航形态与不做项边界。

## 候选方案评估
### 方案 A: 原版 3 组 + RePoi 组 + ListDetail（采纳）
- 优点：与原版结构同构，对照清晰；RePoi 能力独立成组；ListDetail 双窗格体验好。
- 缺点：导航改造成本高于单页堆叠。

### 方案 B: 单页堆叠延续
- 优点：改动最小。
- 缺点：10+ 项后难找难维护。

## 决策结论
一级列表：账号组（个人信息入口复用现有页、账号安全只读 4 行）/ 隐私组（屏蔽设置 3 行、隐私设置 3 组 8 项）/ 通用组（缓存管理占用+清理、关于仅 RePoi 版本号、导出日志）/ RePoi 组（外观主题 4 维、ExHobby 开关）+ 底部退出账号（沿用现状）。不做：推送、注销、意见反馈、三协议、图片质量（cover 系变体比例互不兼容，真实请求验证）、CDN 域名切换、版本更新、贡献榜、邀请码/语言（原版隐藏项）、头像上传（个人信息页纯复用，裁剪链与上传字段名需抓包确认后独立排期）、API 控制台（调试体系删除，仅保留日志系统）。

## 影响
- 积极影响：清单与原版逐项对照；不做项有真实请求验证与第三方客户端定位依据。
- 消极影响 / 迁移成本：ListDetail 导航改造；缺失接口需补（mask/add|del、setting/mysql|riak 读写即隐私 8key+NSFW、user/privacy 读；改密/换绑/注销写与头像上传延后）。
